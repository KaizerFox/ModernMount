# Repository setup checklist

Remaining setup for the public development repository and a future release:

- [ ] Enable GitHub private vulnerability reporting.
- [x] Add the real homepage and source URLs to AppStream metadata.
- [ ] Replace the placeholder application ID if you do not control its namespace.
- [ ] Add branch protection requiring tests and review.
- [ ] Enable Discussions if it will be the support channel.

“ModernMount contributors.” Publishing it does not require adding a personal
legal name, postal address, or email address.
