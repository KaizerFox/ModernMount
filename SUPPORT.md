# Support

ModernMount is an early development project. It is not ready for production
storage management and currently has no guaranteed support window.

Use GitHub Discussions for setup questions and GitHub Issues for reproducible
bugs once those features are enabled. Search existing reports first and include
the app revision, distribution, desktop environment, UDisks version, filesystem
type, and whether the volume is encrypted. Redact UUIDs, device serial numbers,
mount paths containing personal information, and all secrets.

Security issues belong in the private process described in
[SECURITY.md](SECURITY.md).
